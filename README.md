# nayomi-firmware

## Description
Firmware for Nayomi, a simple 4-key macropad.

## Goals
- Support for 8kHz polling rate though USB 2.0 HS
- Support for multiple layout profiles
- Support for multiple lighting profiles
- Support for OpenRGB lighting control
- Rapid-trigger support

## Hardware
- WeAct AT32F405CCT7 MCU
- MT9105ET Hall effect sensors
- WS2812B 5050 ARGB LEDs
- EC11 push-button encoder
- 12x12x6 DIP buttons
